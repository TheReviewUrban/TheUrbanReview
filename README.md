# The Urban Review — Cober

Site de notícias com conteúdo internacional, político, esportivo e variado.

Construído com HTML, CSS e JavaScript puro.

---

## Sobre

The Urban Review é um portal de notícias que reúne diferentes categorias de conteúdo:

- Notícias internacionais
- Política
- Esportes
- Variedades
- Outros temas do cotidiano

O objetivo é entregar informação de forma limpa, rápida e organizada.

---

## Tecnologias

- HTML5
- CSS3
- JavaScript

---

## Como rodar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/the-urban-review.git
```

2. Abra o arquivo `index.html` no navegador  
   ou use um servidor local:

```bash
python -m http.server 8000
```
