# TheUrbanReview
📰Esse projeto é sobre um site jornalistico, criado para repassar informações virtualmente para o público.

## 🔧Funcionalidades
* Botão de modo claro/escuro.
* Aba de comentários para os úsuarios.
* Selecionamento de paginas sobre as noticias.
* Mudanças de cores para as páginas selecionadas.
* Slides de notícias.

---

## 🖥️Tecnologias Utilizadas
- HTML
- CSS
- Java Script
- GIT e Github
- Visual Studio Code

---

## ❓Como rodar?
* 1-Baixe o repositório (Clique no botão "Code" Download Zip)
* 2-Extraia a pasta
* 3-Abra o arquivo `index.html` no navegador  
   ou use um servidor local
```bash
git clone https://github.com/seu-usuario/the-urban-review.git
```
